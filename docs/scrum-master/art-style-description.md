# Descripción del Estilo de Arte

Versión 1.0.0

## Clasificación de Cambios

- Mayor
  - Añadir o eliminar una entrada de Adjetivos o Características Principales
  - Reescribir el contenido de una entrada de Características Principales de forma no equivalente
- Menor
  - Reorganizar la lista de Adjetivos
  - Reescribir el contenido de una entrada de Características Principales de forma equivalente
- Parche
  - Cambiar el formato del documento

## Adjetivos

1. Enérgico
2. Contemporáneo
3. Expresivo
4. Natural
5. Minimalista
6. Ingenioso

## Características Principales

- Técnica visual: Ilustración digital
- Trazos: Bien definidos y naturales
- Color: Predominio monocromático (rojo)
- Personajes: Siluetas humanas estilizadas
- Composición: Narrativa y contextual
- Personalidad: Enérgica
- Sensación: Motivación
